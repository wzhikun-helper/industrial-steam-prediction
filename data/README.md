# Data Directory

本目录用于保存工业蒸汽量预测项目使用的原始数据和后续可能生成的处理后数据。

## 目录结构

```text
data/
├── raw/
└── processed/
raw/

用于保存原始数据文件，原则上不直接修改原始数据。

zhengqi_train.txt：训练集，包含 38 个匿名输入特征 V0～V37 和目标变量 target。
zhengqi_test.txt：测试集，包含与训练集对应的 38 个输入特征，但不包含 target。
processed/

用于保存经过预处理、特征工程或中间转换后得到的数据。

当前主实验采用 Pipeline 完成标准化等操作，因此没有单独生成大规模预处理数据文件，该目录暂时保留供后续扩展使用。

数据处理原则
原始数据保持不变，避免覆盖或修改源文件；
数据读取后首先保留独立副本；
缺失值、重复值、无穷值和异常值均在建模前进行检查；
对异常值不进行简单删除，而是结合模型类型和实验结果进行判断；
标准化、特征筛选和 PCA 等操作尽量放在 Pipeline 中完成，以避免数据泄漏。
