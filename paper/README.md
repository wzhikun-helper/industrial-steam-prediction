\# Paper Directory



本目录用于保存工业蒸汽量预测项目对应的中英文论文材料，包括论文正文、参考文献、插图、表格以及排版源文件。



\## 论文计划



本项目计划整理两篇论文版本：



\- 中文论文

&#x20; - 参考《浙江大学学报（工学版）》近期相关文章的论文结构、写作风格和版式组织；

&#x20; - 内容包括题目、摘要、关键词、引言、数据与方法、实验结果、讨论、结论和参考文献；

&#x20; - 图表编号、正文引用方式、章节组织和参考文献格式尽量按照《浙江大学学报（工学版）》的规范进行整理；

&#x20; - 重点展示模型比较、参数优化、模型融合、SHAP 可解释性分析和误差分析结果；

&#x20; - 正式撰写时需选取《浙江大学学报（工学版）》近期与机器学习、预测建模或工业数据分析相关的论文作为版式和行文参考。



\- 英文论文

&#x20; - 按 ACM MM 官方论文模板进行整理；

&#x20; - 使用英文重新组织论文内容，而不是对中文论文逐句直译；

&#x20; - 实验结果与中文论文保持一致；

&#x20; - 保留 ACM 官方模板、BibTeX、图片和必要源文件。
