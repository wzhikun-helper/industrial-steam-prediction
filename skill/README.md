\# Skill Directory



本目录用于保存工业蒸汽量预测项目对应的可复用 Skill 文档、版本记录和测试结果。



\## 目标



本项目的 Skill 不是简单记录代码，而是将完整机器学习流程整理成一套可重复执行的操作规范，包括：



\- 输入数据要求；

\- 数据质量检查；

\- 特征分析与处理；

\- 模型训练与比较；

\- 参数优化；

\- 模型融合；

\- SHAP 可解释性分析；

\- 误差分析；

\- 最终模型训练与预测；

\- 结果保存与完整性检查。



\## 计划文件



后续将在本目录中逐步建立：



\- `skill\_v1.md`

&#x20; - 第一版完整工作流。



\- `skill\_v1\_test.md`

&#x20; - 第一版实际执行过程中发现的问题和测试记录。



\- `skill\_v2.md`

&#x20; - 根据第一版测试结果修改后的第二版工作流。



\- `skill\_comparison.md`

&#x20; - 对比 v1 和 v2 的差异、改进点以及仍然存在的问题。



\## Skill 内容要求



每个版本应至少包含以下内容：



1\. 使用场景；

2\. 输入文件；

3\. 输出文件；

4\. 环境依赖；

5\. 数据检查步骤；

6\. 数据分析步骤；

7\. 特征处理步骤；

8\. 模型训练与评价步骤；

9\. 参数优化方法；

10\. 模型融合方法；

11\. SHAP 可解释性分析；

12\. 最终预测与模型保存；

13\. 完成标准；

14\. 常见问题及处理方式。
