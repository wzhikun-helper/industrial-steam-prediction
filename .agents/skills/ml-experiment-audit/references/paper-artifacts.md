# Paper and PDF safety review

Map figures/tables to saved CSVs and model/split versions; compare values without
overwriting either source. Inspect plotting scripts for hardcoded results and write
targets before running any command. Aggregated data cannot supply invented beeswarms,
confidence intervals or sample-level distributions. Keep explanation/model boundaries.

For LaTeX, inspect engine/class, includegraphics paths, figure vs figure*, float source
position, barriers, bibliography and final build logs. Scientific audit alone does not
authorize compile/render/plot. If explicitly authorized later, copy to a fresh allowed
directory, preserve frozen image bytes, compile citations to stability and view every
rendered page. Never certify layout from text extraction alone. Separate official
template evidence from editorial preferences and unparsed DOC/DOCX limitations.

Report figure/table pages, overfull/underfull, missing glyphs, font substitutions,
undefined citations, bibliography issues and visual limitations separately. Preserve
uncertainty definitions, sign conventions, all samples and exact numerical precision.
